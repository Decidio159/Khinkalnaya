# Хинкальная — сайт ресторана грузинской кухни

Сайт ресторана "Хинкальная" в Перми.

## 🌐 Просмотр сайта

Сайт доступен по адресу: https://decidio159.github.io/Khinkalnaya/

## 📄 Страницы

- **Главная** (`index.html`) — первый экран с анимацией, хиты меню, о кухне
- **Меню** (`меню.html`) — полное меню с 65 позициями и фильтрами
- **Бронь** (`бронь.html`) — бронирование столика онлайн
- **Контакты** (`контакты.html`) — адрес, карта, телефон, график работы

## 🍽️ О ресторане

- **Адрес:** Пермь, Советская ул., 62
- **График работы:** ежедневно 12:00–23:00
- **Телефон:** +7 (951) 935-20-10

## 🛠️ Технологии

- Чистый HTML5, CSS3, JavaScript
- Адаптивная верстка (mobile-first)
- Система шаблонов для многостраничника
- WebP изображения с оптимизацией

## 📝 Для разработчиков

Сайт собирается из шаблонов в папке `_шаблоны/`:

1. Редактировать меню: `меню.json` → запустить `python меню-собрать.py`
2. Редактировать страницы: файлы в `_шаблоны/страницы/` и `_шаблоны/куски/`
3. Собрать сайт: `python инструменты/собрать.py --проект "сайт"`

⚠️ **Не редактировать** напрямую файлы `index.html`, `меню.html`, `бронь.html`, `контакты.html` — они генерируются автоматически!
